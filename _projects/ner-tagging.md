This repository is part of the **Computational Linguistics** course offered by Saarland University for the Winter Semester of 2023/24 taught by Prof. Dr. Alexander Koller.

This project explores **Named Entity Recognition (NER) in code-switched (CS) data** using neural approaches. We train models using two techniques: one with the **original dataset from CALCS 2018 Shared Task** and another with **augmented data generated from the same dataset**. The results are compared to analyze the impact of data augmentation on NER performance in multilingual contexts.
