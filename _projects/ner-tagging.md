This project is part of the **Computational Linguistics** course offered by Saarland University for the Winter Semester of 2023/24 taught by [Prof. Dr. Alexander Koller](https://www.coli.uni-saarland.de/~koller/).

This project explores **Named Entity Recognition (NER) in code-switched (CS) data** using neural approaches. I trained models using two techniques: one with the **original dataset from CALCS 2018 Shared Task** and another with **augmented data generated from the same dataset**. The results are compared to analyze the impact of data augmentation on NER performance in multilingual contexts.

I have a special soft spot for multilingualism in general, and I wanted to build a project based on this domain. At the same time, my exposure to Transformer architecture and neural language models was rudimentary and I decided to go with a simple approach of NER tagging for the code-switched data. In future, I want to extend some work on code switching and neural models, without a doubt! 

Source code can be found in <a href="https://https://github.com/NiranjanHegde26/Code-Switched-NER-Tagger" _target="blank">GitHub.</a>
