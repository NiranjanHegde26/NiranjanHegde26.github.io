Simple Hotel Reservation Portal designed using Angular 8, Node.js, Express and MySQL as database. Uses MVC Pattern. This was designed as part of the "Databases Management" course during the 6th Semester, BE. But, I'd rathter call it a fun project where we tried some newer tech stacks for that time and (sort-of) reinvented the wheel. However, some hands-on on Node.js later helped me during my stint as a Software Engineer when I had to build API and architecture using Node.js. 

The code is accessible in GitHub. <a href="https://github.com/NiranjanHegde26/hotel-reservation-portal" _target="blank">Click here!</a>
