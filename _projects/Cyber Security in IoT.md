This project-cum-thesis partially fulfilled the requirements of the BE in Information Science and Engineering. It focuses on the security vulnerabilities of IoT devices, particularly their susceptibility to **Distributed Denial of Service (DDoS) attacks**. IoT networks can be hijacked, turning devices into "zombies" that flood and crash a target server. To address this, the project proposes a **deep learning-based approach** to classify malicious data packets.  

Unlike previous studies that used non-IoT-specific datasets, this project utilizes the **BoT-IoT (UNSW-2018 IoT Botnet) dataset**, which includes real-world IoT network transactions. The model employs a **Supervised Deep Belief Network (DBN)**, trained on **2.5 million data points** and tested on **674,486 samples**. Model performance is analyzed using **different RBM epochs (5 and 10)** and evaluated through **metrics like accuracy, precision, recall, and F1-score**.
